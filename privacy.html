プライバシーポリシー

あんだんて（以下「当方」）は、講座・個別プログラムの運営と、その運営のために当方が使うツールにおいて、個人情報を以下のとおり取り扱います。

1. 取得する情報

  • お申し込み・お問い合わせの際にいただくお名前・連絡先
  • 講座・個別セッションの録画データ

2. 利用目的

  • 講座・個別プログラムの提供と、受講者さまへの録画アーカイブの共有
  • お問い合わせへの回答・ご連絡

3. Googleアカウント連携（YouTube）について

当方は、講座録画を当方自身のYouTubeチャンネルへ「限定公開」でアップロードするために、Google（YouTube Data API）との連携を利用しています。この連携は当方のアカウントのみで使用し、第三者のGoogleアカウント情報を取得・保存することはありません。Google APIから取得した情報の利用は、Google API Services User Data Policy（Limited Use要件を含む）に従います。

4. 第三者提供

法令に基づく場合を除き、ご本人の同意なく個人情報を第三者に提供することはありません。

5. 管理

取得した情報は、漏えい・紛失が起きないよう適切に管理し、不要になったものは削除します。

6. お問い合わせ

個人情報の取り扱いについてのお問い合わせは、andante.no.satchan@gmail.com までご連絡ください。
